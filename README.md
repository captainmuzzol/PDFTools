# PDF工具箱

一个功能强大的PDF文件处理工具，提供多种格式转换和文件处理功能。用于完全本地化的PDF处理。

## 功能特点

- **PDF转Excel**：将规整的PDF表格（如电子账单等）转换为Excel文件
- **PDF转Word**：支持两种转换模式
  - 普通模式：适用于文本型PDF文件（如案件文书等）
  - OCR模式：通过OCR技术识别图片型PDF文件中的文字
- **PDF转图片**：将PDF文件转换为高质量PNG图片
- **PDF转PPT**：将PDF文件转换为PowerPoint演示文稿
- **PDF拆分**：支持按页码范围拆分PDF文件

## 技术特点

- 使用PyQt5构建现代化图形界面
- 支持文件拖拽操作
- 多线程处理，避免界面卡顿
- 集成Tesseract-OCR引擎，提供高质量文字识别
- 完全本地化运行
- 支持批量处理和自定义设置

## 系统要求

- Windows操作系统
- Python 3.8+

## 主要依赖

- PyQt5：GUI界面框架
- pdfplumber：PDF文件解析
- PyMuPDF (fitz)：PDF处理
- python-docx：Word文档处理
- openpyxl：Excel文件处理
- python-pptx：PPT文件处理
- Tesseract-OCR：光学字符识别

## 使用说明

1. 安装程序（可在Releases中下载对应版本，支持国产系统麒麟、银河麒麟（arm64））
2. 启动程序后，将PDF文件拖入指定区域
3. 选择需要的转换功能：
   - 转换为Excel：适用于表格类PDF
   - 转换为Word：可选择是否使用OCR
   - 转换为图片：生成高清PNG图片
   - 转换为PPT：自动调整为A4纸大小
   - 拆分PDF：输入起始和结束页码
4. 转换完成后，文件将保存在原PDF所在目录

## 注意事项

- PDF转Excel功能仅适用于规整的表格文件
- OCR识别可能需要较长处理时间
- 建议在转换大文件时耐心等待
- 如遇到问题，请确保PDF文件格式正确
